# イベントカレンダー

サークルのイベント予定と参加者を月ごとに管理できる、オフライン対応のカレンダーです。

## このアプリでできること

- 参加確定、参加予定、〆切の登録、編集、複製、削除
- カレンダー上の種別ラベル表示をイベントごとに設定
- 同じ日付に複数あるイベントの優先表示を選択
- 1イベントにつき最大4名の参加者とスペース番号を登録
- サークル名、サークルロゴ、参加者を管理
- 種別ごとの背景色・文字色と、新規登録時の既定色を設定- 参加者によるイベントの絞り込み
- 登録内容をブラウザへ自動保存
- 種別を選択してPNG、PDF、CSV形式で出力
- 出力対象として選択した種別を次回以降も保持
- 全データをJSON形式でバックアップ
- JSONバックアップからデータを復元

## 始め方

1. ダウンロードしたZIPを任意のフォルダへ展開します。
2. フォルダ内の `index.html` をダブルクリックします。

`index.html` と `assets` フォルダは同じ場所に置いたまま使用してください。
アプリケーションのインストールやインターネット接続は不要です。

## 基本的な使い方

1. 「管理」でサークル情報と参加者(メンバー)を登録します。
2. カレンダーの日付、または「イベントを登録」から予定を登録します。
3. 左側の参加者一覧で、表示するイベントを絞り込めます。
4. 「設定」で週の開始曜日や参加確定・参加予定・〆切の既定色を変更できます。

スペース番号を入力すると、カレンダーの日付行右側にも表示されます。

## 保存とバックアップ

登録内容は使用中のブラウザへ自動保存されます。PC、ブラウザ、またはファイルの保存場所を
変更する前に、「出力」からJSONバックアップを保存してください。

「設定」の「JSONから復元」を使うと、現在のデータはバックアップの内容へ置き換わります。
プライベートブラウズでは、終了時にデータが削除される場合があります。

## 出力形式

- PNG：選択した月・種別のカレンダー画像
- PDF：選択した月・種別を印刷画面から保存するA4横向きPDF
- CSV：選択した種別を含む、Excelなどで開けるイベント一覧
- JSON：イベント、参加者、設定を含むバックアップ

## 対応環境

PC版のChrome、Edge、Firefoxの最新版を推奨します。
